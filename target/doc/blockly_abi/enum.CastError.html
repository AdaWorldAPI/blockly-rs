Expand description

Why a block record could not be cast into a function body.

Variants§

§

UnknownOpcode

The block type (with its dropdown code, if any) has no entry in the ogar-blockly codebook. NEVER guessed: an invented mapping baked into a permanent codebook is worse than a refusal.

Fields

§ty: String

The Blockly block type.

§code: Option<String>

The dropdown code that accompanied it, if any.

§

WideLiteral

A field value exceeds one immediate byte and needs the constant pool, which is a named follow-up rather than a shipped surface.

Fields

§ty: String

The block whose field is too wide.

§value: String

The literal text.

§

UnresolvedRef

A variable reference whose slot this crate cannot resolve — it does not own the variable table. Refused rather than assigned a guessed index.

Fields

§ty: String

The block carrying the reference.

§id: String

The Blockly variable-model id.

§

MutatorUnsupported

The block carries a mutator payload (extraState) that decides its shape — how many sockets it has. Refused rather than lowered to a call that silently omits it; per-block-type mutator schemas are their own wave.

Fields

§ty: String

The block carrying the payload.

§

UnencodedValueParam

A dropdown code the codebook cannot turn into a byte — either an argument whose option set does not name it, or a code on a block whose resolution takes no code at all. Refused rather than dropped: dropping it would lower math_constant[PI] and math_constant[E] to identical calls.

Fields

§ty: String

The block type.

§code: String

The dropdown code with no encoding.

§

ConstantPool

A wide literal could not be interned — wider than a facet, or the pool is full. The remedy for a full pool is a function split, never a wider index; the remedy for an oversized literal is the continuation encoding, which is a named follow-up.

Fields

§ty: String

The block carrying the literal.

§value: String

The literal text.

§source: PoolError

What the pool said.

§

TooManyValues

The block carries more immediates than one call can hold. The remedy is a wider [LaneShape], or a block shape the palette models with a dedicated slot — never a silently truncated call.

Fields

§ty: String

The block type.

§offered: usize

How many fields it offered.

§

Body(BodyError)

The program did not fit the node’s call budget, or a call carried an immediate the lane shape cannot store. The remedy is a split into two functions (or a wider shape), never a bigger row.
